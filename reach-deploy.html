Reach

Deploy Reach in one tap

This page puts all the app files on your GitHub, adds your database keys, and turns on hosting. Your token is only used on this page and is never saved.

How to get a token (2 minutes)
  1. Open github.com/settings/personal-access-tokens/new in Chrome.
  2. Token name: reach-deploy. Expiration: 7 days.
  3. Repository access: Only select repositories, then choose reach.
  4. Under Permissions, add Administration, Contents and Pages, and set each to Read and write.
  5. Tap Generate token, copy it, and paste it above.

Find both in Supabase: tap Connect at the top of your project. Never paste a secret or service_role key. You can leave these empty and run this page again later.

Prefer uploading by hand?

Download all 10 app files in one tap. If Chrome asks to allow multiple downloads, tap Allow. Supabase keys typed above go into config.js.
